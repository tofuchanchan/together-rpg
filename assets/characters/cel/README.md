# 战士关键帧小样

入口：`cel-lab.html`。范围仅东南 SE、东北 NE 的待机、走路、普攻，不替换游戏角色，不延用失败的细碎部件拼装。

## 素材与绘制

- `source/idle-SE.png` / `idle-NE.png`：原版 warrior.png 第28/20帧的原像素，无损提取。
- `source/reference-*.png`：原版对应方向的走路及战斗姿势接触表，用于约束造型、配色、笔触。
- `source/{SE,NE}-{walk,attack}.png`：内置 imagegen 参考原版生成的四张完整姿势序列；每张4×2，共32个绘制姿势。不是人工手绘成品，仍需要视觉验收。提示见 [prompts.md](prompts.md)。
- 根目录四张 PNG 为机械裁切、登记、打包后的运行图集；`warrior.json` 记录边界、头部登记点、脚底及每张源图的统一等比缩放。

运行 `node tools/prepare-cel-warrior.mjs` 重建。不拉宽身体、不单独缩放头/四肢，也不在帧之间做半透明混合。完整姿势不能像骨骼皮肤那样任意换装：新装备需要补对应姿势，本次不承诺完整换装系统。

## 动画实现

- 待机保持原图，只有严格红色范围内的披风与邻接黑线做±0.006弧度微摆；先在原分辨率合成，再整体等比缩放，防止分片边界重采样产生细碎接缝。
- 走路8个关键帧循环0.56秒，约14.3个姿势/秒；页面刷新率独立，不把60Hz刷新声称为60张新绘帧。
- 普攻按现有 combat-motion.js 的蓄力/生效/收势时间编排，第4张姿势在0.12秒击出。采样函数支持攻速缩放；工坊没有实际伤害模拟。
- 逐帧、四分之一速度、原版叠加及游戏尺寸参考用于验收。右侧只是缩放参考，并非已替换游戏后实战截图。

## 已验证与未验证

3项时间采样测试、8项浏览器检查；待机静止与原图逐像素一致，披风摆动时受保护区域变化为0。已实看姿势序列、原版对照、叠加、缩小预览与标准游戏客户端截图。

新绘走路/攻击存在生成式原画的帧间笔触、披风轮廓变化，未宣称逐像素一致或最终美术通过。尚未制作其他6方向、技能/闪避新原画、完整装备换装；未替换正式游戏渲染。下一步应先完成这两个方向的视觉验收，再扩大制作范围。
