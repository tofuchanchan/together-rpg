# 战士分层样板

此目录是 Canvas 独立 PNG 部件原型，不是 Spine 工程。无需 Spine 编辑器或 Spine Runtime。原有角色图集不被覆盖，默认游戏仍使用原版；`layered-lab.html` 提供原版静态对照、八方向动作、换装和可选实战预览。

## 不可变美术参照

`source/original-warrior-reference.png` 来自原有战士图集：银灰尖顶圆盔、黑色眼孔、青绿短衣、深棕短靴、红色披风、青盾和米白盾徽。保留原有粗黑轮廓、软笔触、大头短身比例。拆层用于补齐关节后方被遮挡区域，不授权重新设计角色。

所有方向须与原版并排检查。当前是重绘样板，不能声称逐像素一致；原版仍为最终参照。未露出的裸头、铜盔、斧、圆盾是换装验证样件，不属于原版默认外观。美术修正记录与最后生成提示见 [prompts.md](prompts.md)。

## 文件契约

- `source/warrior-body.png`：头、银盔、躯干、髋、右腿、左腿。
- `source/warrior-limbs.png`：右上臂、右前臂、右手、左上臂、左前臂、左手。
- `source/warrior-equipment.png`：剑、斧、青盾、圆盾、披风、铜盔。
- 每张源图 6 行 × 8 列，列为 S、SW、W、NW、N、NE、E、SE。共 144 个独立部件。
- `body.png` / `limbs.png` / `equipment.png`：2048 × 1536 运行图集，每格 256。`warrior.json` 保存裁切、透明边距、部件索引、武器握点与尖端。
- `rig-contract.json`：骨骼、左右手与插槽语义。不是可直接导入 Spine 的格式。

`node tools/prepare-layered-warrior.mjs` 只做透明连通域识别、裁切、打包、握点登记，不重绘像素；源图由内置 imagegen 编辑生成。构建脚本使用本机 PNGJS 路径，浏览器运行不依赖 PNGJS。

## 运行边界

动作由 `src/coop/layered-pose.js` 采样，PNG 刚性关节装配由 `layered-warrior.js` 绘制。待机仅披风小幅摆动，身体不作整体扭曲。移动腿相位与攻击独立，左右手按解剖语义固定，装备交换不改变战斗数值。

工坊 60 格为连续动作采样，不是 60 张手绘帧。换装导出只保存装配参数。完整动画曲线仍在代码中；未来接入 Spine 需另做绑定与曲线迁移，不能直接导入此 JSON。尚未实现网格蒙皮、布料物理、法师/弓手独立重绘和正式装备属性系统。

可通过工坊“试穿进入实际战斗”验证战士渲染；查询参数只影响外观。卸下武器也不会取消游戏的普攻。实体手柄手感和人工美术最终验收尚未执行。
