# D 三职业插画精灵

战士、法师、弓手以本项目选定的 D 双人示例图为参考，通过内置 imagegen 生成透明 PNG，并已接入实际战斗、选人、HUD 与动作工坊。

- warrior.png / mage.png / archer.png：运行时图集，每张 2048 × 2048，64 个单元。
- 同名 JSON：原图裁剪、原图来源、方向、帧、统一脚点及显示比例。
- source：生成器原始透明图及针对错误朝向补画的修正图，保留原始 alpha。
- prompts.md：实际生成提示词与参考图。

每张图集为 8 列 × 8 行，每单元 256 × 256，脚点 (128, 210)。前 32 单元为移动，后 32 单元为战斗。每组内部按 S、SW、W、NW、N、NE、E、SE 排序，每方向 4 单元。具体索引以 JSON 为准。

移动：待机、左脚接触、经过姿态、右脚接触。战斗：预备、释放/命中、收势、低身闪避/格挡。朝向为独立绘制，运行时不使用水平翻转补方向。个别源图换手错误通过选用同方向正确姿态或补画修正。

`node tools/prepare-character-sprites.mjs` 从透明区域识别行列，按头部和脚底校准位置，统一角色比例，保留武器边距后打包。没有以代码重新描画角色。模型命中仍由战斗时钟决定，PNG 只负责显示。

动作工坊 16 格时间轴是播放采样。当前是关键姿态版本，技能会复用对应出招帧；不是每技能独立的 16 帧手绘长动画。所有图像由内置工具生成，未使用 Python 图像编辑或 API CLI。
