# D 插画美术资源

按本项目已确认的豆豆角色标准重做。实际游戏与 art-lab.html 共用这里的 PNG 图集。

| 运行资源 | 内容 | 单元数 |
|---|---|---:|
| forest.png | 林间遗迹背景 | 1 张整图 |
| enemies.png | 哥布林、蘑菇暴徒，各 8 方向 × 4 姿态 | 64 |
| props.png | 苔石、碎石、树桩、木桶、柱、旗、灌木、蕨草、蘑菇、拱门、树、树冠 | 12 |
| icons.png | 技能、属性、操作与系统图标 | 20 |
| ui.png | 面板、卡片、按钮、禁用态、技能槽、头像框、血条与经验条 | 16 |
| effects.png | 剑弧、旋风、冰霜、爆破、命中、尘雾，各 4 阶段 | 24 |
| projectiles.png | 魔法弹、火球、箭、救援、盾冲、阴影与标记 | 16 |

共 152 个透明图集单元，另有 1 张背景。英雄的 192 个单元继续使用 assets/characters。

source 保存 imagegen 源图，prompts.md 保存实际提示词。参考图为 output/coop-design/D-coop-combat.png 和 output/character-rework/roster.png，均来自本项目。没有提取或复制第三方游戏素材。

使用 node tools/prepare-world-art.mjs 重新打包。工具识别透明间隙；怪物按相连轮廓切分，避免长武器跨越行边界时被裁切。source/cuts 是机械切片中间产物。哥布林西南/西/西北出手与蘑菇西北方向采用补画，按头部面积统一比例。图集每个单元保留透明边距，脚点锚定地面。

manifest.json 描述每帧所在页、矩形、有效内容边界、锚点和显示比例。UI 使用九宫格缩放；ui 子目录是同一皮肤的独立切片，供 HTML 外壳使用。

绘制层读取真实图片。文字、实时血量/冷却/救援进度、敌人精确攻击范围、调试判定和小地图位置点由代码驱动，保证表现与实际数值一致。旋风先旋转再投影到地面，预警显示在地面法术之上。

这是关键姿态版本：每只怪物有两张步态、一张蓄力和一张出手 × 8 方向。特效为四阶段动画，结合透明度与时间播放；不是每动作独立高帧数逐帧动画。当前单房型、两类敌人与既有六技能已覆盖，没有新增 Boss 或地图。

验证：node tools/verify-world-art.mjs；报告和实际运行截图位于 output/art-overhaul。完整战斗回归仍使用 tools/verify-coop.mjs。效果审查截图含刻意布置的多特效场景，其性质与真实战斗截图在报告中分开记录。
