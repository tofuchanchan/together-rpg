## 双人操作

本图按 P1 键盘 + P2 手柄设计；角色职业可互换，图中仅以战士与法师为例。第三职业弓手由 AI 控制。

后续明确支持双手柄。输入层从测试版起按两个可绑定设备的玩家槽位设计，P1 不固定为键盘；实体双手柄支持仍待接入与验收。

八方向动画、连续摇杆移动、手感初值、参考资料与验证要求见 [实现约定](implementation-contract.md)。其中数值为待调试初值，尚未实现或验证。

- P1：WASD 走位，Q 盾冲，E 旋风斩，Space 闪避。
- P2：左摇杆走位，X 火球，Y 冰霜环，A 闪避。按键为本图的 Xbox 字母布局示例。
- 普攻自动执行，不设普攻操作按钮。每人独立技能、冷却、血量。
- P1 青色、P2 橙色，同时保留文字编号；AI 中性色，不与玩家混淆。
- 单一战场与共享镜头。实现时镜头需按两位玩家位置取中点，在限定范围缩放；达到可视边界时限制继续分离，AI 保持跟随。尚未实现或验证。
- 共享经验，个人构筑。清房升级时整个战场暂停，每人有独立随机三选一；确认者显示就绪，全部确认后恢复。AI 自动按职业选取。升级数值仅为界面占位，未经过平衡测试。
