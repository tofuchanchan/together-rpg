# 同行 · 战士动作工坊

当前交付：八方向战士动画试验场，不是完整肉鸽游戏。美术为原创低多边形运动样板，尚未迁入旧项目最终角色造型。

已选正式美术方向：D「极简豆豆冒险」（粗黑边、圆润角色、大色块）。双人同屏战斗与升级界面设计见 `output/coop-design/index.html`，操作约定见 `output/coop-design/README.md`。目前是设计稿，运行中的动作样板尚未换装，也未实现双人操作。

## 运行

在项目目录运行 `node tools/serve.mjs`，访问 http://127.0.0.1:4173/ 。使用本地 HTTP 服务，不能直接双击 HTML（浏览器的 ES module 限制）。运行时依赖已本地保存，不访问 CDN。

## 操作

- 动作预览：待机、跑动、自动普攻、移动普攻、盾冲、闪避；点击八方向卡切换朝向。
- 暂停、上一帧、下一帧、时间轴拖动；0.25/0.5/1 倍播放，0.5–2 倍攻速和移速。
- 自由试跑：WASD / 方向键移动；Q 盾冲；空格闪避；P 暂停；F 全屏。
- 点击地面放置训练木桩；进入射程后自动普攻。可关闭自动普攻。
- “脚点 / 判定”显示脚底、朝向与普攻射程。木桩计数仅记录自由试跑中的真实命中，预览与拖动时间轴不造成伤害。
- 390px 布局适配了预览面板；自由试跑以桌面键盘为目标，没有实现触屏摇杆或双人输入。

## 素材与实现

- `tools/rig.js`：统一关节模型、固定右手剑/左手盾、正交 45°摄像机、六组动作层；Three.js 仅用于离线生成。
- `assets/warrior/`：六张本地 PNG 图集和 manifest。八方向，每方向 16 帧，共 768 个图集单元。上下身组合成完整人物，这不是 768 张独立整人动画。
- `src/model.js`：固定时间步进、自动普攻、动作取消、命中、移动碰撞、冷却和动画采样。
- `src/app.js`：Phaser 显示、上身与腿部独立播放、八方向对照、木桩、场景深度排序、调试 UI。
- `tools/bake.mjs`：从统一源文件重新烘焙图集。需要服务器先启动。

普攻不改变玩家位置；移动阶段与攻击阶段各自连续。移动朝向和攻击朝向独立。闪避可取消普通攻击，已取消动作不会留下延迟命中。命中按模拟时间判定，不依赖是否绘制了某个动画帧。

测试工具默认使用本机已迁移的 Playwright，可通过 `PLAYWRIGHT_MODULE` 指定其他安装路径。标准客户端副本 `tools/web-game-client.mjs` 来自 develop-web-game 技能，仅修改模块导入路径并使用 .mjs 扩展名；未改测试行为。

## 验证

执行 `node --test tests/model.test.mjs`：15 项通过。

执行 `node tools/check-atlas.mjs`：768 个单元非空且边缘未裁切；挥剑、盾冲的首尾与待机首帧共 32 组逐像素比较通过。报告 `output/atlas-check.json`。

执行 `node tools/verify.mjs`：六种动作、四个代表方向、暂停、逐帧、拖动、自动普攻、键盘移动、盾冲与闪避、速度控制、全屏、390px 布局共 15 项记录通过，页面错误为空。截图和结果 `output/verification/`。

执行 `node tools/web-game-client.mjs --url http://127.0.0.1:4173 --click-selector '#play-mode' --actions-file tools/smoke.json --iterations 1 --pause-ms 200 --screenshot-dir output/standard-client`：标准客户端完成，截图和状态已检查。

未执行：真实手机性能、手柄、异地联机、最终角色美术验收、长期帧率测量。八方向动画的运行效果仍需结合用户试玩判断。

## 已知边界

- 动画预览中的跑动为原地步态，盾冲和闪避为循环位移演示。真实位移和伤害在“自由试跑”中检查。
- 这是战士样板，不包含法师、弓手、AI 队友、升级或完整关卡。
- 上下身为同一模型分层烘焙；极端反向移动的腰部扭转尚未用额外过渡动作精修。
- 闪避是压低重心的快速跨步，未制作翻滚。
- 低多边形模型用于确定比例与动作规则，不能作为原角色美术验收完成的证据。
