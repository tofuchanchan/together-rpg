## 操作

标题页使用左摇杆或十字键选择，A 确认；用手柄选择“开始冒险”会自动认领 P1。选人页同样用方向导航按钮、A 执行、B 返回标题，可选择单人或双人模式及职业，职业可以重复；第二只未绑定手柄按 A / Start 加入 P2。选择“绑定手柄”后，在对应手柄上按 A 或 Start 认领，B 取消；P1 与 P2 都能绑定手柄。没有手柄时默认使用两套键盘布局。开局没有 AI，第五关后的商店开始提供招募。

| 设备 | 移动 | 技能 1 / 2 | 闪避 | 升级选择与确认 | 升级重掷 |
|---|---|---|---|---|---|
| P1 键盘 | WASD | Q / E | Space | W / S，E 确认 | R |
| P2 备用键盘 | 方向键 | 小键盘 1 / 2 | 小键盘 0 | 上 / 下，Enter 确认 | 小键盘 3 |
| 标准布局手柄 | 左摇杆 | X / Y | LB（PS 为 L1） | 摇杆或十字键，A 确认 | Y |

手柄 A 只作确认，战斗闪避改为左肩键 LB / L1，避免清波或升级瞬间误选奖励；X / Y 仍为两个技能。界面采用 Xbox 标准位置标识，PS 标准映射对应 A＝×、B＝○、X＝□、Y＝△。

P / Escape / 手柄 Start 暂停；暂停页用方向导航、A 执行、B 返回，可继续战斗、重新绑定设备、调整反馈、打开图鉴或返回选人／标题。升级过程中也可暂停处理设备。窗口失焦和设备断开会暂停，断开的设备需明确重新认领。F 或菜单全屏按钮切换全屏；浏览器不允许原生全屏时铺满游戏可用窗口，再次确认或 Esc 退出。升级重掷只消耗本人次数；商店刷新消耗共用金币，长按只消费一次，双人分别消费自己的次数。

升级替换页面按 B 取消；具备两种可用饲料元素时，X 切换元素。商店 B 关闭详情／取消 AI 替换，在主商店页则选中“离店”，再按 A 确认。结算页可通过焦点选择精英挑战、继续、重开、无尽或返回。相同手柄重新连接后按 A 认领原位置；更换设备则在暂停页选择对应玩家的“绑定手柄”。误切换为键盘后，原手柄仍可按 Start 打开暂停并重新绑定。

玩家普攻自动，只操作移动、Q/E 和闪避。正常开局无技能，首次清波保障一个主动；核心从第三次清波起进入随机池，不固定赠送。主动等级、形态、转换组件和进化分别占用奖励。经验必须捡取地面蓝晶，满经验立即暂停选择属性；四个被动槽满后可明确替换并查看依赖影响。每人每局三次重掷，无 Boss 补充。第 10 关可在揭示奖励前选择高阶奖励或重塑；第 14–16 关可主动挑战一次精英。

`build-lab.html` 的六个链接显式携带 `?trial=...`，用于立即体验已配置的构筑。试炼不修改生命、移速、敌人或第一波规则，开局不再自带 AI；不携带该参数的游戏保持从零构筑。

## 冒险图鉴

- 游戏顶部“图鉴”或 I 打开，Esc 关闭；手柄 View 打开／关闭，方向键／左摇杆导航筛选与条目，LB / RB 切分类，A 查看，B 逐层返回，Start 关闭。详情页上下滚动、左右选择关联条目；类型筛选用左右切换。
- 技能与构筑 113 条（含职业、属性、前置与配方），装备 22 条（12种外观、6词条、4品质），怪物 24 条（13种普通怪、1首领、稀有度与词条）。分裂弹因职业限制分为两个条目。
- 支持职业、类型与关键词组合筛选；相关条目可跳转。进化配方明确区分“满足条件”和“随机抽到”，外观不冒充固定装备属性。
- 战斗中查阅自动暂停，关闭恢复；原本已暂停、失焦或手柄断开时不会自动恢复。升级候选、商店库存和游戏随机状态保持。
- 独立图鉴支持手机列表／详情切换和可分享的条目地址；仅供查阅，不解锁技能或赠送装备。图鉴支持手机不代表战斗已有触屏操作。

## 商店、换装与招募

- 第 5 / 10 / 15 / 20 关清理后进店，每次 3 件共享装备 + 1 名随机候选。双人分别确认离店。
- 一把武器、一套完整防具，职业绑定；可为本人、同伴或 AI 选择穿戴者。购买立刻替换，旧件消失，本轮无背包、售卖或退币。
- 普通 / 精良 / 稀有 / 传奇，随机主属性和 0 / 1 / 2 / 3 条战斗词条，关卡提高数值与品质机会。装备不占被动槽。
- 刷新同时更换三件商品与候选，首店 10 金，每次再涨 6 金；后续商店初始价随关卡提高。
- 候选等级取真人平均等级四舍五入，属性点=等级−1，构筑点=⌊(等级−1)×0.65⌋；现有构筑预算的前两点优先学 Q/E，点数不足不免费补齐，后续继续随机合法配点。稀有度仅加基础属性，随机双件装备计入招募价。
- 空位直接加入，满三人时明确选择替换 AI，真人不可替换。新队友共享后续经验并自动选择成长与构筑。
- 商店 W/S 或方向键选项，A/D 或左右键换穿戴者，Q / NUM1 / 手柄 X 查看详情；R / NUM3 / Y 花金币刷新。

详细价格、词条与接口见 [装备设计](SHOP-EQUIPMENT-DESIGN.md) 和 [招募设计](RECRUITMENT-DESIGN.md)。

## 当前实现

- 三职业已按 D 示例图重做为透明 PNG 精灵；游戏、选人和头像直接读取图集，不再用几何图形拼角色。走路和普通出招使用原 PNG 的脚部、持武器手臂切片做连续关节运动，头和躯干保持刚性；动作时间与命中判定分离。
- 怪物、背景、12 种场景物件、20 个图标、六组特效、弹道和全部游戏 UI 已统一为同画风插画 PNG。共八张世界图集、192 个透明单元与一张背景；选人、战斗、升级、暂停、手柄绑定、失败和清房均已接入。资源与提示词见 assets/world。
- 输入独立绑定到玩家槽位，连续角度与模拟推幅、径向死区、短缓存、动作取消；失焦清输入，重连须认领。
- 双人达到同屏距离边界时，可沿边走位或向内闪避；边界在移动前处理，不再事后把角色拉回怪堆，倒地队友复起也不会强拉远处玩家。
- 固定 120Hz 战斗模拟，渲染独立；命中只结算一次，无敌和冷却不受表现顿帧影响。
- 三职业独立前摇、命中、收招时间；动作帧、刀光、出弹共用时间轴。普攻可被闪避取消，技能按各自动作窗口开放取消；多数技能允许走位，迎击盾阵明确保持原地防守。
- 角色与怪物具有定向受击回弹、渐退亮色和局部短停；命中火花对齐接触位置，伤害数字避开血条，不冻结队友。
- 弹道按线段的第一接触点结算怪物和墙体，贯穿箭逐个命中一次；修复墙前漏判、后排先中以及近身目标被枪口偏移跳过。远程普攻在出手时进行有限移动预判；基础火球与贯穿箭锁定起手瞄准点，释放时按当前站位校准方向，不追踪目标。
- 待机只让披风、帽尖或衣摆的局部 PNG 切片围绕连接点轻摆；身体、脸和装备保持原位，不再整张拉伸或条带变形。受击时局部眼睛/面甲切换为痛苦表情，背面不画眼睛。
- 远程 AI 在安全射程内边退边射，识别怪物预警与来弹，选择安全躲闪落点。保持局部避障；复杂迷宫的全局寻路不在当前实现内。
- 双人共享经验、金币、镜头和升级暂停，各自有独立血量、技能、四个被动槽、核心、进化和觉醒。升级保留溢出经验，确认后继续原战斗；满四被动的技能奖励页可独立选择“保留构筑 · 放弃本次奖励”，不占随机三张候选。替换、保留、重塑均须双方分别确认。
- 核心、资源来源、资源兑现与回收拆分，六条职业主线形成十二种互斥进化；额外弹道、灵犬 / 纸鸦 / 荆种、闪步回路、陷阱、拾荒、异常转换可跨职业混搭。来源互相递归被禁止，冷却额外返还共用每次施放 35% 上限。
- 七张独立透明技能 PNG 已接入：青金盾阵、红白旋刃、橙金炎爆、蓝白冰枪、寒潮领域、金色穿甲箭、紫色影箭。地面与弹道分层，敌方预警保持可辨；素材、源图与提示词在 `assets/builds/`。
- AI 按实际持有组件决定技能时机，缺少转换件不会空等资源；无怪时原地附近巡游，不追随玩家。拾经验、金币及本人构筑碎片，优先避险、吃药与救援；赶往倒地队友时可用技能清障，进入救援范围后优先读条。疏敌时自动攻击优先处理可见治疗者，保留近身威胁和猎印优先规则。
- 战士生命 200、索敌 145、普攻命中半径 205。地图约 2694 × 1690，世界镜头缩放乘 0.8，HUD 保持尺寸。药瓶基础回复 35；普通怪掉率降至 0.4%，精英 / 稀有 / 传奇分别为 1.5% / 3.5% / 7%。选完清波奖励存活者休整回复 15%，换房再回复 12%；波内不自动回复。
- 普通关每房两波，持续补怪：击杀当帧补位，没有死亡也周期增援。首波一／二／三人的初始数量为6／11／16，存活上限14／25／36，总预算48／96／144；倒地不临时降压。后续密度、数量与成长上升，持续时长和总预算结束后清理残敌。P1修复与复测见 [修复报告](P1-FIXES-V08.md)。
- 三种新增弱小怪（芽豆、尘团、飞蛾）形成主要怪群，配合原十类特殊怪。13 类怪物有独立碰撞半径；触碰角色造成伤害，共享 0.55 秒受击无敌。稀有等级逐步进入，蓝 / 紫 / 金色实体轮廓对应 1 / 2 / 3 条词条。萨满同时存活上限为队伍人数（1／2／3），超额刷新改为骷髅，避免三人队无限累积治疗者。
- 每第 10 关为荆冠古王 Boss 战：五个技能、65% / 30% 血量转阶段，后两阶段使用带安全通道的扩散环大招。使用原创八姿态透明 PNG。
- 旋风与地面特效绘于角色下层；前向刀光和弹道按脚点深度排序。
- 动作工坊支持三职业、7 动作、8 方向、逐帧、慢放与 PNG 导出。
- 每职业图集 64 单元：8 方向 ×（4 个移动姿态 + 4 个战斗姿态），共 192 单元。每单元 256 × 256，脚点 (128, 210)；位移、局部物件摆动、受击反馈由播放层控制。实际素材在 assets/characters，来源与提示词见该目录 README 和 prompts.md。
- 走路相位按实际移动距离推进，起步和停止约 55ms 平滑过渡，抵墙不空转。普攻前摇、击出、收招连续衔接；移动攻击与命中短停期间保留腿部步态。24 套方向切片在加载阶段预热，首次移动不做切图计算。
- 动作工坊连续播放，时间轴为 60 等分采样，并非新增 60 张手绘帧。普通出招使用原画局部切片；盾冲、闪避、旋风保留专用关键姿态，弹道和法术特效独立。

新增小怪与召唤物是六张透明 PNG 四姿态图集，见 `assets/universal/`；经验、金币与小型状态标记采用轻量几何绘制。素材只扩展本轮内容，保持已验收三职业原角色图。

构筑模拟共 120 组：六方向各 10 个普通场景种子，采用预置的五次合法技能奖励预算、真实 AI 和后续随机奖励，60 组均在 200 秒内完成三波、存活并产生构筑兑现。另 60 组 Boss 场景为每角色 18 次技能奖励、20 次属性强化、带队友并移除召唤怪的独立 fixture；4.6–7.6 秒结束明显过快，防守流来不及形成 Boss 循环。该结果验证部分状态与输出链路，不能证明自然成长、Boss 召唤阶段或难度平衡通过。

又补充 72 场保留召唤的 Boss 对照（每组合三个种子，含三人队与单人隔离）：同等级基础三人队无核心／形态／被动也约 8.52–9.03 秒，主角无扣血；等卡数属性基线约 4.77–4.97 秒，新六方向约 4.83–7.32 秒。由此推断原 Boss 对成长后三人队压力不足，不能一概归因于新构筑失控。单人壁垒约 27.62 秒、五次兑现与 23.29 吸收，能观察到防御循环；单人狙猎约 8.84 秒，比等卡数基础弓手快约 32%，仍需调参。等卡属性基线包含人工预算转换，不能当作正常游戏奖励路线。详情见 [构筑深化验证记录](BUILD-DEPTH-DESIGN.md#14-首批实现的验证记录与边界)。复跑：`npm run test:build-simulation -- --boss-compare --compare-seeds=3`。

## 边界

- 双手柄输入通过模拟设备路由测试；没有接入实体手柄做兼容性和延迟验收。不支持未标准化设备的自定义按键校准，未知布局需另外验证。
- 当前游戏美术已统一为参考图生成的插画素材；音效仍为合成占位。角色和怪物采用关键姿态，特效采用四阶段序列，更细的中间帧与各技能专属长动画尚未制作。
- 目前一种扩大后的房型、13 类常规敌人、一种三阶段 Boss、20 关 + 无尽、六条主线十二高级分支；没有随机地图、存档或联网。小怪多为四姿态、Boss 八姿态，左右镜像，不是独立八方向。
- 构筑包含暴击、闪避、攻速、减伤、范围、冷却及燃烧/流血/闪避爆发等联动。数值用于样板，未完成长期平衡。
- 本次已完成节奏重设计和通用构筑方案；更早十八方向草案的其余职业主线、商店与装备系统仍未实施，不与本轮 25 通用卡 / 6 觉醒混淆。
- 未进行真实双人体验验收、实体设备端到端延迟测量、长期性能压力测试或移动端触屏操作验证。
- 原动作工坊资料保存在 README-lab.md。
