# 同行 · 林间远征

D「极简豆豆冒险」画风的本地小队肉鸽。支持单人 + 双 AI、双人 + AI；三职业、十种常规敌人、稀有词条、每十关 Boss；经验属性升级、九个职业核心、十四种被动、主动分支与六条进化路线。详细规则见 [构筑设计](ROGUELITE-DESIGN.md)。

## 操作

开始界面选择单人或双人模式，再选择不同职业；剩余职业交给 AI。选择“绑定手柄”，在对应手柄上按按钮认领；P1 与 P2 都能绑定手柄。没有手柄时默认使用两套键盘布局。

| 设备 | 移动 | 技能 1 / 2 | 闪避 | 升级选择与确认 |
|---|---|---|---|---|
| P1 键盘 | WASD | Q / E | Space | W / S，E 确认 |
| P2 备用键盘 | 方向键 | 小键盘 1 / 2 | 小键盘 0 | 上 / 下，Enter 确认 |
| 标准布局手柄 | 左摇杆 | X / Y | A | 摇杆或十字键，A 确认 |

P / Escape / 手柄 Start 暂停；F 全屏。窗口失焦和设备断开会暂停。暂停界面可重新绑定设备、切换反馈、震屏与判定显示。升级过程中也可暂停处理设备。

玩家普攻自动，不自动追怪；AI 会自动走位战斗。开局只有普攻和闪避，主动槽为空。清波可习得战士盾冲 / 旋风斩、法师火球 / 冰霜环、弓手贯穿箭 / 扇射，或选择被动。经验满立即暂停三选一属性，保留溢出经验；每波结束独立选择技能。红圈是敌人攻击预警；玩家倒地后，任意存活队友在附近停留 2 秒可救起。

## 当前实现

- 三职业已按 D 示例图重做为透明 PNG 精灵；游戏、选人和头像直接读取图集，不再用几何图形拼角色。走路和普通出招使用原 PNG 的脚部、持武器手臂切片做连续关节运动，头和躯干保持刚性；动作时间与命中判定分离。
- 怪物、背景、12 种场景物件、20 个图标、六组特效、弹道和全部游戏 UI 已统一为同画风插画 PNG。共八张世界图集、192 个透明单元与一张背景；选人、战斗、升级、暂停、手柄绑定、失败和清房均已接入。资源与提示词见 assets/world。
- 输入独立绑定到玩家槽位，连续角度与模拟推幅、径向死区、短缓存、动作取消；失焦清输入，重连须认领。
- 固定 120Hz 战斗模拟，渲染独立；命中只结算一次，无敌和冷却不受表现顿帧影响。
- 三职业独立前摇、命中、收招时间；动作帧、刀光、出弹共用时间轴。普攻可被闪避取消，技能在命中后开放取消，不锁走位。
- 角色与怪物具有定向受击回弹、渐退亮色和局部短停；命中火花对齐接触位置，伤害数字避开血条，不冻结队友。
- 弹道按线段的第一接触点结算怪物和墙体，贯穿箭逐个命中一次；修复墙前漏判、后排先中以及近身目标被枪口偏移跳过。远程普攻在出手时进行有限移动预判。
- 待机只让披风、帽尖或衣摆的局部 PNG 切片围绕连接点轻摆；身体、脸和装备保持原位，不再整张拉伸或条带变形。受击时局部眼睛/面甲切换为痛苦表情，背面不画眼睛。
- 远程 AI 在安全射程内攻击、贴近时边退边射；选择可通行的躲闪方向避开预警和来弹，低血量选择安全药瓶并绕过简单障碍。保留救援、技能和成长选择，尚非完整寻路。
- 双人独立血量、技能冷却、角色标记；共享经验、镜头和升级暂停；每人独立随机三选一。12 类属性、14 种可升三级被动（四槽）、9 个互斥职业核心；每个主动可选扩域/重击/速发分支，再按配方进化。
- 战士基础生命 200、索敌距离 145，实际普攻命中半径 155 → 205。地图在 v0.4 基础上面积再翻倍至约 1905 × 1195；世界镜头缩放乘 0.8，UI 不缩小，实际战斗距离不统一削减。普通怪药瓶掉率 28%，基础回复 35；稀有怪掉率更高。
- 普通关每房两波，每波四批定时增援；首房两波至少持续 48 / 56 秒，总计 36 / 40 只怪。后续时间与数量增加；清空队列、计时结束且清敌后才领奖。
- 怪物生命、伤害、移速和攻击频率随累计波次成长。精英/稀有/传奇用蓝/紫/金色轮廓表示，分别带 1/2/3 条不重复随机词条。
- 每第 10 关为荆冠古王 Boss 战：五个技能、65% / 30% 血量转阶段，后两阶段使用带安全通道的扩散环大招。使用原创八姿态透明 PNG。
- 旋风与地面特效绘于角色下层；前向刀光和弹道按脚点深度排序。
- 动作工坊支持三职业、7 动作、8 方向、逐帧、慢放与 PNG 导出。
- 每职业图集 64 单元：8 方向 ×（4 个移动姿态 + 4 个战斗姿态），共 192 单元。每单元 256 × 256，脚点 (128, 210)；位移、局部物件摆动、受击反馈由播放层控制。实际素材在 assets/characters，来源与提示词见该目录 README 和 prompts.md。
- 走路相位按实际移动距离推进，起步和停止约 55ms 平滑过渡，抵墙不空转。普攻前摇、击出、收招连续衔接；移动攻击与命中短停期间保留腿部步态。24 套方向切片在加载阶段预热，首次移动不做切图计算。
- 动作工坊连续播放，时间轴为 60 等分采样，并非新增 60 张手绘帧。普通出招使用原画局部切片；盾冲、闪避、旋风保留专用关键姿态，弹道和法术特效独立。

## 边界

- 双手柄输入通过模拟设备路由测试；没有接入实体手柄做兼容性和延迟验收。不支持未标准化设备的自定义按键校准，未知布局需另外验证。
- 当前游戏美术已统一为参考图生成的插画素材；音效仍为合成占位。角色和怪物采用关键姿态，特效采用四阶段序列，更细的中间帧与各技能专属长动画尚未制作。
- 目前一种扩大后的房型、十类常规敌人、一种三阶段 Boss、可循环关卡及六种技能进化；没有随机地图、存档或联网。新增八种怪物各四姿态，Boss 八姿态，左右镜像，不是独立八方向。
- 构筑包含暴击、闪避、攻速、减伤、范围、冷却及燃烧/流血/闪避爆发等联动。数值用于样板，未完成长期平衡。
- 未进行真实双人体验验收、实体设备端到端延迟测量、长期性能压力测试或移动端触屏操作验证。
- 原动作工坊资料保存在 README-lab.md。
